# Kawa Apple Silicon 测试版安装说明

## 这个版本适合谁

- 使用 Apple Silicon（M 系列芯片）的 Mac 用户。
- 使用苹果自带拼音、苹果自带日文输入法和 ABC，并希望分别设置一个快捷键。
- 愿意参加小范围测试的用户。

应用最低构建目标是 macOS 12.0。已经实际验证的系统和功能请查看同包的测试记录；最低构建目标不代表所有中间版本都经过测试。Intel Mac 不在本测试版范围内。

## 安装与首次设置

1. 解压测试包，找到 `Kawa.app`。需要长期使用时，可自行将它复制到“应用程序”文件夹。
2. 确认系统已添加这三种输入源：苹果拼音、苹果日文、ABC。可在系统设置的“键盘”中查找“文本输入／输入源”的编辑入口。
3. 打开 Kawa，点击菜单栏图标进入设置。
4. 分别录入中文、日文、英文的快捷键。不要给两种输入法设置同一个组合；如果录入时提示冲突，请选择另一组。
5. 关闭设置窗口后，在普通文本输入框中试用。只要 Kawa 仍在运行，已保存的快捷键就应继续生效。

日文快捷键的目标是苹果菜单中的正常“平假名”输入模式，可以继续转换汉字。它不应停留在上次使用的片假名或英数模式。

| 设置中的名称 | 对应输入法 |
| --- | --- |
| Apple Pinyin | 中文，苹果自带拼音 |
| Japanese Hiragana | 日文，普通平假名模式，可转换汉字 |
| ABC | 英文 |

Kawa 会保存设置，在下次启动程序时恢复快捷键。此测试版没有新增登录时自动启动功能。

## “Apple Silicon 原生”是什么意思

这个版本的程序为 M 系列芯片直接编译，架构名是 `arm64`，不需要用 Rosetta 转译 Intel 指令。源代码里的构建设置和最终生成的程序都需要检查，不能只凭应用图标或项目使用 Swift 判断。

本次构建的具体检查结果在 `testing.md`。开发者可用 `file Kawa.app/Contents/MacOS/Kawa` 查看，预期输出包含 `Mach-O 64-bit executable arm64`。

## 提示与常见问题

- **输入法未启用**：先在系统设置中添加对应的苹果输入源，再重试。
- **快捷键被占用或重复**：修改冲突组合。程序可以检查部分系统冲突和 Kawa 内部重复，但不能保证发现所有第三方应用的快捷键。
- **切换没有确认成功**：查看菜单栏的错误状态和说明。记录当时使用的应用、目标输入法、是否存在未完成的候选词，并提交复现步骤。
- **没有成功通知**：检查 Kawa 的通知选项以及系统通知授权。通知未授权不应妨碍输入法切换。

## 测试版的签名限制

本包用于本机及小范围测试，没有完成 Developer ID 正式分发签名和 Apple 公证。从网络下载后，macOS 可能阻止打开或提示无法验证开发者。

只使用你能核实来源的测试包。遇到系统阻止时，请先把提示内容反馈给提供者；不要为了运行本包关闭系统安全保护。正式公开分发会另行处理签名与公证。

## 反馈与退出

反馈时请提供 macOS 版本、芯片型号、测试包版本、相关快捷键和复现步骤。不要附带密码或私人文档。

可以从 Kawa 设置窗口退出程序；退出后由 Kawa 注册的快捷键应解除。删除应用前，先退出正在运行的 Kawa。应用没有要求修改或删除系统输入源。
